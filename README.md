# .github

Default issue forms and pull request template for every repository owned by
[@mohiwalla](https://github.com/mohiwalla) that doesn't define its own.

- `.github/pull_request_template.md`: Problem / Change / Scope / Verification, with
  before/after evidence for UI changes. Based on [T3 Code](https://github.com/pingdotgg/t3code)'s
  template and [laddu](https://github.com/mohiwalla/laddu)'s adaptation.
- `.github/ISSUE_TEMPLATE/`: bug report (adapted from T3 Code) and feature or change forms.
  Blank issues are off.

Changes go issue → short-lived branch → PR (`Fixes #N`) → rebase or squash merge.
